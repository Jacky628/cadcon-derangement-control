## 0. 为什么要重测

复制实验（`repl_verdict.json`，outcome=REPLICATED）把主结果的样本从 v1 的 76 条 / 38 个唯一
程序换成 400 个去重、profile 分层的唯一程序。Test D 仍停留在 v1 样本上，由此产生两条必须
处理的问题：

1. **推断证据与因果证据不在同一样本上。**主张「wrong intent 的伤害需要习得的 header→program
   映射」由两条链支撑：wrong-vs-baseline（现为 n=400）与 Test D 交互（仍为 n=38）。
2. **更具体的问题**：论文 Appendix B（L263 / L285）记载，v1 的 dissociation 由 pure-NGON
   不成比例地承载——interaction 0.545 为全表最大，剔除 NGON 后 seed 0 失去显著性（p=0.32）。
   **而 pure-NGON 恰是复制样本上 wrong-vs-none 点估计为正的那个 profile**（+0.1111, n=39）。
   两者测的不是同一个对比（交互 vs wrong-vs-baseline），因此不构成直接矛盾；但关键 profile
   在两个对比中表现不一致，而因果证据又恰好倚重它，这一点不能靠 Limitations 的一句话带过。

重测成本低：R 臂三个 checkpoint（`f4_text_shufhdr_seed{0,1,2}`）在盘，**无需任何训练**；
M 臂的 correct / wrong 数据复制实验已产出。只需补 6 个 eval 作业。

## 1. 开盲状态声明（必须先讲清楚）

**M 臂在本增补冻结时已开盲。**`repl_text_correct_p04` 与 `repl_text_shuffled_p04` 是复制实验
主判据的一部分，其 per-seed 效应与 per-profile 点估计已被检视并写入
`复制实验_RUN_LOG_20260806.md`。因此 `drop_M` 对作者而言是已知量。

**R 臂在新样本上尚未产生任何数据。**Test D 的统计量为
`interaction = drop_M − drop_R`，在 `drop_R` 未知时其值不可推知，判据的通过与否完全由
尚未观测的 R 决定。**故本增补在 Test D 的意义上仍属事前。**

这一非对称性如实记录于此，并须在论文中说明：Test D 的重测是在 M 臂已知、R 臂未知的条件下
预注册的。任何读者都可据本文件的 sha256 与 git 提交时间独立核验这一时序。

## 2. 唯一的改动：样本

| 项 | F4 母文档 | 本增补 |
|---|---|---|
| 分析集 | v1 的 n=76（38 个唯一程序，需簇内平均） | **复制实验的 n=400 唯一程序**（`replication_frozen_lists.json`，无需聚类） |
| profile 集合 | 6 个冻结 profile | **11 个 profile**；护栏 (b) 仅计入 n≥15 的 10 个，`CIRCLE+NGON+TALL`(n=6) 只报点估计 |
| 非零对护栏 (c) | 绝对值 15 | **60 = 0.15n**（与复制实验 §4 同阈值、同严格读法） |
| `drop_M` 来源 | 冻结 `spike_results/geom_scores.jsonl` + 复现 assert（M 均值 0.557/0.305） | **`repl_results/geom_scores.jsonl`**；复现 assert 相应改为核验 M 臂均值与 `repl_verdict.json` 一致 |
| prefix | 40% | 40%（不变） |
| seeds | 0,1,2 | 0,1,2（不变） |

**其余一切不变**：同 seed 配对 Wilcoxon（`zero_method="pratt"`、单侧、`method="asymptotic"`）、
方向取 mean(d) 符号、全零差计为不显著、反向一票否决、≥2/3 seed 方向 + ≥2/3 seed p<0.05。

## 3. R 胜任度门（前置，逐字沿用母文档，阈值不变）

Test D 生效**仅当**在 40% 前缀、≥2/3 seed 上：

- `R_correct` 与 `R_shuffled` 的执行计入式 4-tag recall **各 ≥ 0.30**；
- `R` 的 executability **≥ baseline_p04 的 executability − 0.10**。

阈值 0.30 与 0.10 为母文档事前选定，**本增补不因样本更换而调整**。用于比较的
`baseline_p04` 取复制实验的实测值（executability 0.578–0.650，主度量均值 0.406）。

- 须报告 `R_correct` / `R_shuffled` 的**绝对值与 executability，永不只报差值**。
- **门不过 → Test D 判 UNINTERPRETABLE / 对照无效**，回落母文档 §0 的保守降级 headline，
  明确不得写 "dissociation confirmed"。

## 4. 评测矩阵

6 个 eval 作业，全部 prefix 0.4、`eval_subset_size=400`、`--frozen-list` 绑定同一冻结样本：

| condition | ckpt | seeds | eval_mode | train_mode | header_source |
|---|---|---|---|---|---|
| `replD_R_correct_p04` | `f4_text_shufhdr_seed{0,1,2}` | 0,1,2 | text | text | correct |
| `replD_R_shuffled_p04` | `f4_text_shufhdr_seed{0,1,2}` | 0,1,2 | text | text | shuffled |

M 臂直接复用复制实验已产出的 `repl_text_correct_p04` / `repl_text_shuffled_p04`。

**关键一致性要求**：Test D 要求 M 与 R 在同一 idx 上注入**同一个** wrong header。
`_build_shuffle_plan` 由 `random.Random(seed)` 驱动、对全部 n 个样本一次性构造，而 M 与 R
的 n 与顺序均相同（同一冻结样本、同 `eval_subset_size`），故注入方案逐位一致。
**分析脚本须对此设断言**（沿用 `submission_audit.py` 中
`assert set(m_wrong["header_injected"]) == set(r_wrong["header_injected"])` 的做法），
不一致即中止。

## 5. 护栏（沿用母文档，按新样本缩放）

- **(a) 可执行交集敏感性**：在 M/R × correct/shuffled 四格皆可执行的 idx 上重算，主 dissociation
  方向不得翻号。
- **(b) profile 级方向护栏**：11 个 profile 中 n≥15 的 10 个，(drop_M − drop_R) 的 seed 平均
  mean ≥ 0（方向要求，非显著性）。
- **(c) 非零对计数**：每 seed 非零配对差数 < 60 的 seed 标 underpowered，**且若 ≥2/3 多数在
  剔除该 seed 后不再成立，则判据不成立**（沿用复制实验 A-3 的严格读法）。
