## 1. 条件矩阵（冻结；聚焦 40% 前缀=C3 所在）

**复用 C-spike 冻结数据（不重跑，直接从 `spike_results/geom_scores.jsonl` 取）**：`spike_baseline_p04`、`spike_text_correct_p04`、`spike_text_shuffled_p04`、`spike_text_masked_p04`（各 3 seed）。F4 主实验只测 text（论文主打臂；token 为可选补充 §6）。

**新增 F4a — 随机-header 训练对照模型 R（承重；采用 shuffled-GT 训练，非随机子集）**：
- 训练 `f4_text_shufhdr_seed{0,1,2}`：SFT 时把每个训练样本的 header 换成**另一真实样本的 GT header**，用**精确错位排列（derangement，`_derangement_plan`，无不动点的置换）**于训练集 derive 出的约束上。**关键优点（采纳审查 #3，并强化）**：derangement 使 R 的 header **多重集与 M 逐字节完全相同**（是置换非有放回采样——单元测实证 marginal 精确不变、无 σ(i)=i），只破坏 program↔header 相关性——排除分布漂移的黄金对照。（注：eval 侧 shuffle 仍用 C-spike 冻结的 `_build_shuffle_plan`，不改；仅训练对照用 derangement。随机子集会引入 header 长度/空 header 分布差，弃用。）
- 硬约束：**`header_dropout=0.0`**（否则 R 变 CFG 模型非内容对照，须 assert）；shuffle 用专属 `random.Random(seed)`、按确定的数据集顺序推进（冻结进 code sha256）。
- 评测 R @40%：`R_correct / R_shuffled / R_masked`（3 态 × 3 seed = 9 job）。
- 机制检查 R @0%：`R_correct` × 3 seed（3 job）。

**新增 F4b — 真实模型 M 上的推理剂量-反应（SUPPORTING/探索，非确证；采纳审查 #5）**：
- `M_corrupted`：**腐蚀限制在 4 个被测 tag（TAGS_PRIMARY）**上翻 1-2 个（否则翻 `<MULTI_PART>` 在 4-tag 度量空间不可见、稀释剂量梯度）× 3 seed。
- `M_random`：良构、**size-matched 非空**随机内容 header × 3 seed。**标注为 non-evidential**（不作任何方向证据）。

**总计新增：3 训练 + 18 评测 job。** 标签一律 `f4_*` + 新 `--merge-dir f4_results`。

## 4. 判定规则（冻结）

统计机制同 C-spike：同 seed 配对 Wilcoxon（`pratt`, 单侧, 渐近）；方向=mean(d) 符号；全零差=不显著；n76；反向否决。**drop_M 从冻结 `spike_results/geom_scores.jsonl` 用 import 的 `spike_analysis` recall 函数算，加复现 assert：M 均值须=0.557/0.305（≤1e-6）**（采纳审查 #8）。

### 🚧 前置门 — R 胜任度门（采纳审查 #1，堵地板效应假 dissociation；**Test D 生效前必过**）
Test D 判 "dissociation" **仅当**在 40% 前缀、≥2/3 seed 上：
- **R_correct 与 R_shuffled 的 exec-inclusive 4-tag recall 各 ≥ 0.30**（非平凡高于地板、可比 `baseline_p04≈0.425`），**且**
- **R executability ≥ baseline_p04 executability − 0.10**（baseline_p04 exec≈0.59 → 门≈0.49）。
- **报告 R_correct/R_shuffled 绝对值 + executability，永不只报差值。**
- **门不过（R 贴地板/退化）→ Test D 判 UNINTERPRETABLE / 对照无效 → 回落 §0 保守降级 headline，明确不得写 "dissociation confirmed"。**
- **有效 dissociation 的预注册签名**：`R_correct ≈ R_shuffled ≈ baseline_p04(~0.42)、drop_R≈0`，**两臂皆在地板之上**，对比 `drop_M≈0.25`。

### 主判据 — Test D（dissociation / 交互；仅在胜任度门通过后读）
定义（几何 4-tag recall，n76，per-sample，同 seed，M-seed-s 与 R-seed-s 因 `set_seed` 同 init、评同 idx 同序）：
- **drop_M(i,s)** = M_correct − M_shuffled；**drop_R(i,s)** = R_correct − R_shuffled。
- 对 (drop_M − drop_R) 同 seed 同 idx 配对 Wilcoxon，单侧（drop_M > drop_R），≥2/3 seed 方向 + ≥2/3 seed p<0.05，无反向否决。
- **通过 ⟺ 语义驱动确认**（错内容对"学过内容"的模型伤害显著大于对"忽略 header"的模型）。presence-of-effect，非证 null。

### Test D 附加护栏（采纳审查 #4；report + guard，不改主判据）
- **(a) 可执行交集敏感性**：在 M/R × correct/shuffled 四格皆可执行的 idx 上重算 Test D，主 dissociation 方向不得翻号。
- **(b) profile 级方向护栏**：6 冻结 profile 上 (drop_M − drop_R) 的 seed 平均 mean ≥0（方向、非显著性；防单 profile 主导，尤其 `<TALL>` n=4）。
- **(c) 非零对计数**：报每 seed 的非零配对差数；<15 的 seed 标 underpowered、不得单独承担 ≥2/3 多数。

### 支撑检查（只报，不改主判据；采纳审查 #7）
- **Test M1（内容盲证据仅此一条）**：`R_correct vs R_shuffled` 效应量（预期 ≈0）。**`R_correct vs R_masked` 是 presence 对照非内容证据**（R 训练总见 header，masked=OOD，spread 大属正常），不得当内容盲证据引。
- **Test M2（R 无法仅凭 header，@0%）**：描述性 R_correct@0#（预期≈baseline_p00=0）vs M_correct@0%=0.776。
- **F4b 剂量-反应（same-seed 配对，禁合并 seed）**：correct>corrupted 且 corrupted>shuffled 各在 ≥2/3 seed 成立（mean(d)，各 vs baseline 用冻结 wilcoxon）；**非单调=not-confirmed（不得 spin）**。M_random **non-evidential**。

### 结局→行动（冻结）
| Test D（门通过后） | 裁决 | headline |
|---|---|---|
| 通过 | **语义驱动确认** | 强版 "wrong design-intent hurts"；明写排除分布漂移；对口场接收上修 |
| 失败 或 胜任度门不过 | **分布漂移/失配 或 对照无效**（采纳审查 #7：二者皆排除强语义 headline，§0 降级两种情形下都稳） | §0 ①降级 framing |
